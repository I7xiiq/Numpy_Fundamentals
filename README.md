# 🔢 NumPy Basics & Fundamentals

Welcome to my NumPy learning repository! This project documents my journey in mastering **NumPy** (Numerical Python), the core library for scientific computing and data manipulation in Python.

## 🎯 Learning Objectives

This repository contains scripts and examples covering the following core concepts:

- [ ] **Array Creation:** 1D, 2D, and 3D arrays, `np.zeros`, `np.ones`, `np.arange`, `np.linspace`.
- [ ] **Indexing & Slicing:** Accessing elements, subsetting, and boolean indexing.
- [ ] **Array Manipulation:** Reshaping, flattening, concatenating, and splitting arrays.
- [ ] **Mathematical Operations:** Element-wise operations, broadcasting, and linear algebra basics.
- [ ] **Statistical Functions:** Mean, median, standard deviation, min/max, and aggregations.

## 🛠️ Technologies Used
* **Python 3**
* **NumPy**
