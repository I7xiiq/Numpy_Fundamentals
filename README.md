# 🔢 NumPy Fundamentals & Data Analysis Basics

Welcome to my **NumPy Fundamentals** repository! This project documents my hands-on learning of NumPy (Numerical Python), the core library for scientific computing, data analysis, and machine learning in Python. 

The scripts in this repository serve as a practical reference for understanding how NumPy processes arrays efficiently compared to standard Python data structures.

## 🧠 Topics & Concepts Covered

This repository contains heavily documented Python scripts explaining the following core concepts:

- [x] **Performance & Memory Profiling:** Comparing execution time and memory usage between standard Python Lists and NumPy Arrays.
- [x] **Array Creation & Properties:** Understanding dimensions (`ndim`), shapes (`shape`), capacity (`size`), and memory footprint (`itemsize`).
- [x] **Data Types & Casting:** Exploring default data types, forcing specific types (e.g., `float32`, `int64`), and changing types using `astype()`.
- [x] **Indexing & Slicing:** Advanced slicing techniques for extracting specific elements, rows, and columns from 1D vectors and 2D matrices.
- [x] **Arithmetic Operations:** Performing fast, element-wise mathematical operations on multidimensional arrays.
- [x] **Statistical & Aggregation Functions:** Utilizing functions like Mean, Median, Standard Deviation, Min/Max, and Sum across different axes.
- [x] **Array Manipulation:** Restructuring data using `reshape()` for complex tensors and `ravel()` for flattening arrays (crucial for Computer Vision models).

## 🛠️ Technologies Used
* **Python 3**
* **NumPy**
* **Sys & Time** (Built-in libraries for performance and memory testing)
